# n8n — de spil van de automatisering

Elke workflow staat hier als geëxporteerde JSON in `workflows/`, met dezelfde
naam als in n8n. **De export in git is de bron; de instantie is een deploy.**
Geleerd in GoalBuddies: wat er draait en wat er in de repo staat lopen uit
elkaar in béide richtingen, en dat merk je pas als het misgaat.

Mailsjablonen (HTML) staan in `templates/`; die vallen onder `emoji:controle`.

Zie `docs/decisions/002-stack-en-werkverdeling.md` voor wat in n8n hoort en wat
in Supabase.
