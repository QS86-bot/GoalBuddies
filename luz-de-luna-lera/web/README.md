# web — de frontend uit Bolt

Hier landt de export van Bolt. De prompts waarmee hij gemaakt is staan in
`docs/bolt/PROMPTS.md`; elke prompt is genummerd en de export noemt in zijn
commit welk promptnummer hem opleverde.

Regels die ook voor gegenereerde code gelden staan in `CLAUDE.md`: geen geheim
in de bundel, alle adressen via env vars, elke asynchrone weergave met een
laad-, fout- en lege staat.
